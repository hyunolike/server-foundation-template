REQUEST LIFECYCLE
요청 하나가 지나가는 여덟 지점
표준화는 “모두가 규칙을 지키는 것”이 아니라 규칙이 지나갈 수밖에 없는 지점을 정하는 것이다. 아래 여덟 지점 밖에서는 응답 형식을 손대지 않는다.
INBOUND HEADERS
X-Request-Id (optional) Authorization Accept-Language
OUTBOUND HEADERS
X-Trace-Id (always) Content-Type: application/json
01 · FILTER
TraceIdFilter
요청당 traceId를 만들거나 X-Request-Id를 승계한다. MDC에 넣고 응답 헤더로 되돌려준다.
02 · FILTER
RequestLoggingFilter
본문을 캐싱 래퍼로 감싸 한 줄 구조화 로그를 남긴다. 마스킹 규칙은 여기 한 곳에만 있다.
03 · FILTER (OPT)
SecurityFilterChain
인증 실패도 예외 경로와 같은 봉투로 나가도록 EntryPoint를 교체한다.
04 · INTERCEPTOR
HandlerInterceptor
레이트리밋 · 멱등키 · 감사 로그를 붙이는 확장 지점. 기본 템플릿은 비워 둔다.
05 · BINDING
@Valid + Resolver
요청 DTO 바인딩과 검증. 페이징은 공용 PageRequest 리졸버로 통일한다.
06 · DOMAIN
Controller → Service
봉투를 모르는 유일한 구간. 도메인 DTO를 반환하거나 BusinessException을 던진다.
07 · ADVICE
ResponseEnvelopeAdvice
반환값을 ApiResponse.success()로 감싸고 meta(traceId, timestamp, path)를 채운다.
08 · CONVERTER
Jackson Converter
네이밍 · 날짜 · null 정책을 한 ObjectMapper 설정에서 적용해 직렬화한다.
예외 경로 — 05~06 어디서 갈라지든 07과 같은 모양으로 합류한다
BusinessException
도메인이 던진 의도된 실패. ErrorCode가 들고 있는 HTTP 상태와 코드를 그대로 응답한다.
MethodArgumentNotValid
검증 실패. COMMON_INVALID_PARAMETER 하나로 모으고 필드별 사유를 details에 담는다.
Exception (fallback)
예상 밖 오류. 내부 메시지는 절대 밖으로 내보내지 않고 traceId만 안내한다. 로그는 ERROR로 전량 남긴다.
봉투 제외 경로. /actuator/**, /v3/api-docs/**, /swagger-ui/**, 그리고 파일 다운로드처럼 application/json이 아닌 응답은 07을 건너뛴다. 예외 목록은 프로퍼티로 열어 두되 기본값을 코드에 박아 둔다 — 이 목록이 길어지면 표준이 무너진 신호다.
