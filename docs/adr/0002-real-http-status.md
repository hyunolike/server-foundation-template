# 0002. 실패 응답도 실제 HTTP 상태 코드를 사용한다

- 상태: 수용됨
- 관련: [설계 문서 §6.6](../design/architecture.md)

## 맥락

봉투에 `success` 필드가 있으니 HTTP 상태는 늘 200으로 고정하자는 선택지가 있다. 클라이언트가 한 곳만 보면 되고, 일부 프론트엔드 HTTP 라이브러리가 4xx/5xx에서 예외를 던지는 불편도 사라진다.

## 결정

실패 응답은 `ErrorCode`가 들고 있는 실제 상태 코드로 내보낸다. `success`는 보조 신호다.

## 결과

- 게이트웨이, 모니터링, 브라우저 캐시, 로드밸런서가 읽는 값이 사실과 일치한다. 200으로 고정하면 오류율 지표가 0이 되고 관측이 무너진다.
- 클라이언트는 상태 코드로 대분류를, `error.code`로 분기를 한다.
- `success`와 상태 코드가 어긋날 수 없도록, 봉투를 만드는 세 생산자가 모두 같은 `ErrorCode`에서 상태를 읽는다.
